How to install the extension

Takes about 2 minutes, one time. Works in Google Chrome and Microsoft Edge on a computer.

  1. Download the file with the Download Chrome Extension button above. It is saved as scout-extension.zip, usually in your Downloads folder.
  2. Unzip it. Right-click the file and choose Extract All (Windows) or double-click it (Mac). Move the extracted folder somewhere permanent, such as Documents. Do not delete it later, because Chrome loads the extension from that folder.
  3. Open the extensions page. Copy chrome://extensions into a new browser tab and press Enter. (In Edge use edge://extensions.)
  4. Turn on Developer mode using the toggle in the top-right corner of that page.
  5. Click Load unpacked and select the folder that contains the file manifest.json. The zip contains a folder inside a folder, so open the outer scout-extension folder and choose the inner scout-extension folder.
  6. Done. "Scout for Target" now appears in your extensions list. Click the puzzle-piece icon in the toolbar and pin it if you like.
Chrome may show a "Disable developer mode extensions" message when it starts. That is normal for extensions loaded this way. Click Keep.

How to use it

  1. Click Open Dashboard and sign in (or create an account).
  2. Type a keyword and click Track keyword. A Target tab opens, captures the rankings, sends them to your dashboard, and closes by itself.
  3. Your keywords, rank history and sales estimates are saved to your account and follow you to any browser.
